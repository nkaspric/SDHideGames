# SDHideGames 🎮

**SDHideGames** is a Steam Deck plugin (powered by Decky Loader) designed to declutter your library. It automatically hides uninstalled games from your home screen and library, keeping your interface clean and focused on what you can actually play.

---

## ✨ Features

* **Automatic Cleanup**: Hides uninstalled game entries to show only what's ready to launch on your SSD or MicroSD.
* **Seamless Integration**: Fits perfectly into the Decky Loader sidebar menu.
* **Quick Toggle**: Easily enable or disable the hiding feature with a single switch.
* **Focus Mode**: Ideal for users with large Steam libraries who want to focus on their current "installed" backlog.

---

## 🛠️ Installation

### Prerequisites
* [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) must be installed on your Steam Deck.

### Manual Installation (Development Branch)
1.  Switch your Steam Deck to **Desktop Mode**.
2.  Open a terminal (Konsole).
3.  Clone the repository (DEV branch):
    ```bash
    git clone -b DEV [https://github.com/nkaspric/SDHideGames.git](https://github.com/nkaspric/SDHideGames.git)
    ```
4.  Copy the folder to your Decky plugins directory:
    ```bash
    sudo cp -r SDHideGames /home/deck/homebrew/plugins/
    ```
5.  Restart your Steam Deck or restart the Decky service.

---

## 🚀 How to Use

1.  Press the **"..."** button (Quick Access Menu) on your Steam Deck.
2.  Navigate to the **Decky Loader** icon (plug icon).
3.  Select **SDHideGames**.
4.  Toggle the switch to hide/show uninstalled games.
